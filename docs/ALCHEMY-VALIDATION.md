- 기존 `jobs`의 영구 완료 기록을 기준으로 사용한다. 취소·진행 중·미수행 회차는 제외하고 정정 시 같은 작업의 최신 결과만 집계한다. 따라서 재시작·백업 복원 뒤에도 같은 수율을 재구성하며 별도의 중복 집계 테이블이나 스키마 변경이 필요 없다.
- 제작식·배치 단위·실제 투입 재료/대체재가 다른 기록은 분리한다. 고정 제작식은 공식 산출 단위를 유지한다. 명시적으로 저장한 목표별 수동 수율이 있으면 우선하며 빈칸 저장으로 자동 수율에 돌아간다.
- 기록이 없는 제작식은 산출 가정을 표시한다. 평균 산출이 0인 기록은 횟수 계산을 보류한다. 배포 확인 시점의 운영 DB에는 수율 집계 대상 완료 기록이 없어, 실제 완료 입력부터 평균이 적용된다.
- 목표 상세 앞부분에 `부족한 제작품·중간재`와 `재료 확인`·`횟수 입력`을 제공한다. 중간재 상세는 해당 품목과 하위 재료에 집중한다. 기록이 없는 가변 제작의 실행 횟수는 사용자가 직접 입력한다. 제작품의 안내는 일반적인 외부 수급 문구 대신 실제 제작 방법을 표시한다.

메인은 기존 색상·배경을 유지하면서 프로그램 선택과 두 앱 진입점만 남겼다.

## 이미지와 레시피 자료

170개 품목을 기존 자료와 독립된 BDO Codex 게임 품목 ID로 교차 검증했다. 167개는 정확한 이름과 유일한 게임 아이콘 대응을 확인했고, 곰 피·카프라스의 정수·대왕 고래 오일은 품목 ID와 설명을 추가 대조했다. 같은 이름의 카프라스 퀘스트 아이템은 제외했다. 대왕 고래 오일은 같은 게임 ID 9727의 현행 한국어 명칭인 대양의 오일과 연결했다.

서로 다른 버섯·오일에 연결된 잘못된 이미지와 구형 비약 아이콘을 정정했다. 현재 WebP 원본 170종은 204,252바이트이며 출처·게임 ID·원본 해시·이전 출처를 `alchemy/data/icon-sources.json`에 보관한다. 이전 저장 카탈로그의 PNG 주소도 현재 WebP 아이콘으로 제공한다. Python 3.12 Windows의 MIME 레지스트리와 무관하게 `image/webp`를 명시한다. 게임 이미지의 권리는 펄어비스에 있다.

제작식 87개(공식 패치 대조 38개·보조 DB 대조 49개)의 수량은 이번 변경에서 바꾸지 않았다. 대양의 영약 공식 제작식과 델로티아 가루·정제된 시약 경로를 다시 대조했다. 요구 숙련도 등 미확인 값은 그대로 미확인이다.
