# BDO Suite 연금 검증 기록 — 2026-10-23

## 구현 범위

- 공통 실행기·통합 메인 아래 `barter/`와 `alchemy/`를 분리했습니다. 물교는 기존 API와 저장 위치를 유지하고, 연금은 별도 SQLite와 revision을 사용합니다.
- 연금: 목표·공유 재고 예약·중간재 우선 계산·배치별 제작 경로·대체 재료·기대 수율 계획·실제 제작 차감/산출·부분 완료·취소·정정·원장·백업/복원·카탈로그 편집·화면 설정을 제공합니다.
- 26개 완제품, 87개 제작식, 전체 170개 품목을 등록했습니다. 제작식은 공식 패치 대조 38개, 보조 DB 대조 49개이며 전체 게임 제작 노트의 직접 실사를 뜻하지 않습니다.
- 170개 품목 모두 실제 아이콘을 포함합니다. 출처별로 제작노트 148개, 공식 패치 표 18개, BDO Codex 4개입니다. 원본 PNG/WebP 합계 793,149바이트이며 출처·정확한 품목명·SHA-256을 `alchemy/data/icon-sources.json`에 보관합니다.

## 격리와 성능의 실제 확인 범위

통합 HTML·health 요청만으로는 어느 DB도 생성하지 않으며, 연금 API 요청은 물교 DB를 초기화하지 않는 것을 검사했습니다. 각 작업실은 별도 문서로 이동하며 상대 작업실의 API·프런트엔드 리소스를 요청하지 않습니다. 연금 카탈로그 전체를 전역 클라이언트 상태로 유지하지 않고 상세 캐시를 제한하며, 트리는 펼친 가지를 렌더링합니다.

최종 브라우저의 설정·편집 화면에서 측정한 JSHeapUsedSize는 20,238,196바이트(약 19.3 MiB)입니다. 단일 시점 측정이며 피크 메모리, 장시간 사용, 운영체제 전체 메모리 회수 보장은 검증하지 않았습니다.

## 남은 확인

새 게임 화면에서의 재료·요구 숙련도·산출량 실사는 수행하지 않았습니다. 확인하지 못한 요구 단계는 미확인으로 유지합니다. 기존 설치 실행 파일 교체와 실제 AppData 데이터로 쓰기 검증은 수행하지 않았습니다. 모든 자동 검증은 임시 DB·브라우저 프로필을 사용했습니다.
