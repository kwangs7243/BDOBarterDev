# BDO Suite 통합 앱 검증 기록 — 2026-10-24

## 최종 설치와 구조

실제 Git 소스 루트 `D:\BDO`의 `main`에 통합했다. `barter/`는 기존 물교, `alchemy/`는 연금, `local_app/`는 공통 실행기·서버·native·통합 메인·검증·패키징을 담당한다. 기존 물교 API·저장 위치·인식 출처·원문·검수 의미를 유지한다. 기존 main의 회차 revision·재고 차감·교섭력 0·경로 계산 수정도 함께 병합했다. 별도 작업트리의 느슨한 파일 복사본을 운영 소스로 사용하지 않는다.

일반 실행은 `D:\BDO\BDO 실행.lnk` 또는 `D:\BDO\app\BDO 실행.exe`다. 실행 창은 전용 아이콘과 준비 단계, 통합 앱 다시 열기, 정상 종료 버튼을 제공한다. health 준비 후 브라우저에서 `/` 통합 메인을 연다. `/barter/`와 `/alchemy/`로 각각 이동한다. 실제 바로가기로 실행한 EXE 경로, Chrome의 통합 메인 창, 세 화면의 읽기 전용 동작을 확인했다.

물교 DB는 기존 `%LOCALAPPDATA%/BDOBarter/data/bdo.sqlite3`(스키마 4), 연금은 `%LOCALAPPDATA%/BDOSuite/alchemy/alchemy.sqlite3`(스키마 1)를 사용한다. 실제 물교 DB 9개 테이블의 행 수와 내용 해시, ROI/native 프로필 1개가 설치·시작·조회·정상 종료 전후 동일했다. 기존 연금 DB는 없었으며 첫 조회로 빈 DB만 생성했다. 실제 사용자 재고에 시험 제작이나 보정 거래를 넣지 않았다.

기존 소스·설치 파일·SQLite·ROI 백업은 `D:\BDOBarterDev-archive\20261023-suite-release`에 있다. 운영 환경과 모델은 `_dev/recognition-local/`에 그대로 두며 Git에 포함하지 않는다.
