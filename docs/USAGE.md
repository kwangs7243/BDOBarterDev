# 사용 안내

## 현재 회차와 인식

1. 물교 인식 창에서 대상 게임 창과 영역을 선택합니다. 물교·창고 영역은 별도 저장되며 재시작 후 복원됩니다.
2. 게임 목록을 사용자가 직접 이동하며 F10으로 캡처합니다. 파일·붙여넣기와 지원되는 화면 공유 경로도 사용할 수 있습니다.
3. 인식이 끝나면 대기 스크린샷은 비워지고 결과 목록을 확인할 수 있습니다. 확인이 필요한 필드는 원본 이미지 옆에서 수정합니다.
4. 검수를 마친 뒤 현재 회차에 새로 적용하거나 추가합니다. 저장 성공 후 모달이 닫힙니다. 실패하면 수정 내용이 남습니다.

획득품이 화려한 암염 주괴·화려한 진주 결정이거나, 충분한 판독 근거로 미지원 획득품임이 확인된 행은 미사용 묶음에 들어갑니다. 필요하면 다시 포함할 수 있으며 해결되지 않은 값의 검수는 유지됩니다. 대양 위치에 있다는 이유로 까마귀주화 교환을 제외하지 않습니다.

## 창고와 스케줄

창고 인식·검수 결과를 명시적으로 적용해 재고를 갱신합니다. 창고 판독 대상은 1–4단이고 5단은 창고 PATCH에서 변경하지 않습니다. 품목별 목표와 표시 순서는 저장됩니다.

선택한 모드·재고·물교 목록·교섭력·무게로 스케줄을 만듭니다. 출항 적재는 높은 단계부터 육지품 순서이며 같은 단계에서는 저장한 창고 표시 순서를 사용합니다. 창고 결산은 단계별 한 행으로 표시됩니다. 교환 완료는 서버 저장 후 재고와 교섭력에 반영됩니다.

경유지는 섬·품목 자동완성을 지원합니다. 경유지를 추가했다는 이유로 물교 목록의 교환 행이 자동 생성되지는 않습니다.

## 데이터 위치

운영 DB는 `%LOCALAPPDATA%/BDOBarter/data/bdo.sqlite3`, 캡처 영역 프로필은 같은 data 폴더의 `native-capture-profiles.json`에 보관합니다. 현재 회차·재고·설정·스케줄 슬롯은 앱 재시작 후 복원됩니다.

저장소 업데이트와 사용자 운영 DB는 별개입니다. 개선용 이력을 정리할 때도 재고·회차·설정·ROI는 보존합니다. 사용자 요청 없는 초기화나 캡처 이력 삭제는 하지 않습니다.
