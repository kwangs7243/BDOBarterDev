# 숫자 인식 개선 실험과 결정

날짜: 2026-10-19. 상태: **오프라인 실험 완료 / 제품 미적용**.

물교 정답 표본 확장을 계속하고 ML 전환을 보류하기로 결정했다. 기존 5회차·75장 자료에서 학습 45장, 조건 선택 15장, 평가 15장을 분리하고 숫자 이미지 216종을 대조했다. HOG + 최근접·선형 SVM·RBF SVM을 비교했으며 GPU·외부 API는 사용하지 않았다.

낮은 PC 부하에서 평가 15장·90행을 각 방식 2회 번갈아 재생했다. 다음 시간은 인식 엔진의 중앙값이며 프로세스 시작·캡처·브라우저·저장 시간은 포함하지 않는다.

| 방식 | 엔진 시간 | OCR 호출 | 추가 자동 판독 |
|---|---:|---:|---:|
| 현재 전체 필드 정답 대조 | 12.48초 | 378회 | 0건 |
| 숫자 한 자리 정답 조합 | 11.82초 | 334회 | 4건 |
| HOG + 최근접 분류 | 11.90초 | 332회 | 6건 |

두 추가 방식의 시간 차이는 실행 변동 범위 안이었다. 추가 판독의 관측 오답은 0건이었지만, 기존 OCR도 맞게 읽던 값이므로 정확성·검수 감소는 확인하지 못했다. 검수 여부와 90행의 최종 값은 그대로였다.

넓은 영역의 숫자 누락 검사를 없애 강제로 판독한 후보는 23건 중 12건을 틀렸다. 124→24처럼 전경 추출에서 앞자리가 빠지는 문제라, 높은 분류 유사도로 안전을 보장할 수 없었다. 해당 완화 방식은 채택하지 않았다.

숫자 한 자리 조합은 ML이 생략한 OCR 46회 중 44회를 동일하게 생략했다. 이 방법도 탐색 결과이며 제품에 적용하지 않았다. 모든 정답 숫자를 확보한 것은 아니고, 반복 평가를 새 실사 독립 검증으로 취급하지 않는다. 창고·섬·품목명 ML은 이번 실험 대상이 아니다.

현재 제품은 [인식 안내](../RECOGNITION.md)의 전체 필드 정답 조회와 기존 OCR을 사용한다. 추후 확장은 검증된 표본·숫자 누락 검사·별도 회차 평가를 유지한 뒤 판단한다.
