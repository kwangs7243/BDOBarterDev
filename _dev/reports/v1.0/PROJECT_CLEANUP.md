## 과거 이력 전환

기존 `archive`는 원격 저장소의 `main`과 `v1.0` 태그가 확인된 뒤 삭제했다. 이후 이전 버전은 로컬 복제 폴더가 아니라 Git 커밋, `release/vX.Y` 브랜치와 `vX.Y` 태그로 보호한다.

- GPT 검토 ZIP과 압축 파일은 `.gitignore`로 제외

- 새 버전은 별도 브랜치에서 검증 후 `--no-ff` 병합
