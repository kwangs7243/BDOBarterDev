# 완료 보류 기능 제거 전용 보고서

작성일: 2026-09-24  
대상: `BDO_물교_v1.0.html`

## 결론

스케줄에 표시된 교환을 완료 단계에서 막던 기능을 제거했다. 일반 교환, 5→6, 6→7, 특수 교환과 까마귀주화 교환에 공통 적용된다.

특히 실제 재발 사례인 `까마귀의 둥지 / 청동 촛대 → 까마귀 주화`를 전용 회귀에 고정했다. 재고가 4단 최소보존보다 낮아도 완료 상태, 입력 재고, 교환 목록 수량과 교섭력이 갱신되는 것을 확인했다.

## 제거한 완료 단계 판단

- 최소보존 침범 여부
- 현재 입력 재고가 교환 비용보다 충분한지
- 6→7 전에 대응하는 5→6 카드를 완료했는지
- 특수·무작위·까마귀주화 예외 분기
- 위 조건에 따른 `완료 보류` 메시지와 조기 종료

완료된 카드를 다시 눌렀을 때 이중 차감을 막는 조건은 데이터 손상을 막는 멱등성 장치이므로 유지했다.

## 완료 시 현재 동작

1. 입력품이 마스터 재고에 있으면 비용만큼 차감한다.
2. 차감 결과가 음수가 될 상황이면 0으로 제한한다.
3. 마스터에서 관리하는 출력품은 행별 수율만큼 증가한다.
4. 교환 목록 수량과 교섭력을 차감한다.
5. 카드를 완료 상태로 바꾼다.
