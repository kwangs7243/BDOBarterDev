## 2. 구현 방식

### 슬롯 그리드

- 이미지 전체의 가로·세로 밝은 경계선 주기를 각각 탐색한다.
- 주기 48~54px, 슬롯 폭 42~48px 범위에서 연속된 경계선 쌍을 찾는다.
- 가로·세로 주기와 폭이 일치하는지 확인한다.
- 각 칸의 테두리 대비와 슬롯 뒤 6px 간격의 어두운 영역을 2차원으로 다시 검증한다.
- 고정 캡처 원점은 사용하지 않는다. 검출 실패 시 `SLOT_GRID_DETECTION_FAILED`로 중단한다.

### 아이콘

- `reference/icons/`의 70개 로컬 아이콘만 사용한다.
- 모든 슬롯을 서로 독립적으로 70개와 비교한다.
- 43×43 내부 이미지 중 수량이 겹치는 하단을 제외한 색상 RMSE와 정규화 명암 구조 차이를 결합한다.
- 프로토타입 기준 `최고 점수 ≤ 0.35`, `1·2위 후보차 ≥ 0.045`를 모두 만족해야 확정한다.
- 품목 순서, 행·열 위치, 예상 단계, 미등장 품목 정보는 쓰지 않는다.

### 수량

- 아이콘 판정과 독립적으로 슬롯 우측 하단 `y=28:40`을 8px 폭의 오른쪽 정렬 숫자 셀 4개로 분리한다.
- 흰색 숫자 본체를 `maxRGB > 0.50`, 채널차 `< 0.25`로 추출한다.
- 별도 실제 화면에서 만든 게임 숫자 글꼴 템플릿과 최근접 비교한다.
- 외부 GPT/Gemini/OCR API와 네트워크를 사용하지 않는다.
- 숫자/빈칸 판정차 또는 1·2위 숫자 후보차가 부족하면 `QUANTITY_UNKNOWN`으로 제외한다.

## 8. HTML 통합 판단과 남은 위험

파이프라인 구조와 안전 제외 정책은 HTML 통합 가능한 형태로 검증됐다. 그러나 **즉시 자동 적용 기능으로 HTML에 넣을 수준이라고 확정하지 않는다.** 이유는 다음과 같다.

1. 정상 물교품 3종이 안전 기준에서 계속 누락된다. 잘못 쓰는 것보다는 안전하지만 PATCH 완전성은 100%가 아니다.
2. 기준 70종 중 실제 화면 양성 검증 표식이 없는 14종이 남아 있다: 최고급 굴 상자, 자수정 파편, 훔친 해적단 단도와 5단 11종.
3. 이번 표본은 같은 게임 해상도/UI 배율과 숫자 글꼴이다. 다른 UI 배율, 선택·마우스오버, 압축·리사이즈 화면은 미검증이다.
4. 3자리 수량의 실제 표본이 없다.
5. 현재 임계값은 요청대로 프로토타입 값이며 최종값으로 확정하지 않았다.

따라서 현재 판단은 **독립 도구의 제한된 실사용 시험은 가능, 기존 HTML 자동 통합은 추가 양성 표본 검증 후 진행**이다.
