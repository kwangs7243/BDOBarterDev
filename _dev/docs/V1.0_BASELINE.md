## 기능 기준

- 아이템 마스터와 고신뢰 단일 후보 유사도 보정을 유지한다.
- 특수 교환 입력을 임의의 4~5단품으로 강제 치환하지 않는다.
- 행별 수율이 스케줄과 완료 재고에 동일하게 적용된다.
- 수동 입력 수율을 명시적으로 편집할 수 있다.
- 기존 백업과 새 입력의 충돌 행은 자동 덮어쓰기하지 않는다.
- 스케줄에 표시된 일반·특수·까마귀주화·5→6·6→7 카드는 완료 단계에서 재검사로 보류하지 않는다.
- 입력 재고가 교환 비용보다 적으면 0으로 제한하고, 교환 목록·교섭력·완료 상태는 반영한다.
- 완료된 카드를 다시 눌렀을 때의 중복 반영 방지만 유지한다.
